# 跨域推荐页面布局优化与领域跨越度调节功能开发计划

## 现状分析

### 当前页面布局

- **主页面**：左侧为图书网格列表 + 右侧为热门推荐侧边栏
- **跨域推荐**：通过模态框（Modal）弹出展示，点击图书卡片后弹出详情+跨域推荐
- **交互流程**：用户点击图书 → 弹出模态框 → 模态框内显示详情和跨域推荐

### 当前算法逻辑

- 跨域推荐公式：`FinalScore = CombinedSimilarity × OverlapCoefficient`
- `CombinedSimilarity = a × SemanticSimilarity + (1-a) × KeywordSimilarity`
- `OverlapCoefficient` 由 `β` 参数控制，当前 β=0.25（固定值）
  - overlap=0 → 系数1.0（完全跨域）
  - overlap=1 → 系数0.75
  - overlap=2 → 系数0.50
  - overlap≥3 → 系数0.0（同领域过滤）

## 任务1：跨域推荐页面布局优化

### 设计方案

**核心思路**：将跨域推荐从模态框弹出模式改为主页面直接展示模式，采用"选中态+推荐区"双区布局。

#### 1.1 页面结构重构

**新布局方案**：

```
┌──────────────────────────────────────────────────────┐
│  Header: 📚 图书推荐系统                              │
├──────────────────────────────────────────────────────┤
│  搜索栏 + 排序 + 领域跨越度滑块                        │
├──────────────────────┬───────────────────────────────┤
│                      │                               │
│   图书网格列表        │   跨域推荐面板（右侧）          │
│   (点击选中高亮)      │   - 选中书籍信息卡             │
│                      │   - 领域覆盖统计               │
│                      │   - 推荐结果网格               │
│                      │   - 返回按钮                   │
│                      │                               │
├──────────────────────┴───────────────────────────────┤
│  分页                                                 │
└──────────────────────────────────────────────────────┘
```

**交互流程**：

1. 默认状态：左侧图书网格 + 右侧系统简介/热门推荐
2. 用户点击某本书 → 左侧该书卡片高亮选中 + 右侧面板切换为跨域推荐
3. 右侧面板显示：选中书籍信息 → 领域跨越度滑块 → 跨域推荐结果
4. 点击推荐结果中的书 → 切换选中态，右侧更新为新书的跨域推荐
5. 点击"返回浏览"或空白区域 → 取消选中，右侧恢复系统简介

## 任务2：加权效用函数与领域跨越度调节功能

### 2.1 领域跨越度滑块设计

**滑块参数映射**：

| 滑块位置 | β值   | overlap=0 | overlap=1 | overlap=2 | overlap≥3 |
| ---- | ---- | --------- | --------- | --------- | --------- |
| 左端   | 0.10 | 1.0       | 0.90      | 0.80      | 0.0       |
| 中偏左  | 0.15 | 1.0       | 0.85      | 0.70      | 0.0       |
| 中间   | 0.25 | 1.0       | 0.75      | 0.50      | 0.0       |
| 中偏右  | 0.35 | 1.0       | 0.65      | 0.30      | 0.0       |
| 右端   | 0.45 | 1.0       | 0.55      | 0.10      | 0.0       |

**滑块UI设计**：

```
领域跨越度: [====●========]
💡 当前设置：平衡相关性与跨域发现，推荐结果兼顾领域相近与领域差异
📌 推荐值：β=0.25（中间位置），可获得最佳的跨域推荐体验
```

**设计要点**：

1. **滑块本身不显示档位名称**：滑块为连续值控件（范围0.10~0.45，步长0.05），滑块轨道上不标注任何档位文字
2. **说明文本位于滑块下方**：在滑块控件正下方放置两行说明文本
   - 第一行（💡图标）：动态描述当前滑块数值对应的具体效果，随滑块拖动实时更新
   - 第二行（📌图标）：固定显示推荐的最佳跨域效果数值设置（β=0.25）
3. **动态效果描述映射**：
   - β ≤ 0.12："侧重相近领域，推荐结果偏向与原书领域高度相关的书籍"
   - β = 0.15："适度拓展领域，推荐结果以相近领域为主，少量跨域探索"
   - β = 0.20："兼顾相关与跨域，推荐结果在相近领域和跨领域间取得平衡"
   - β = 0.25："**推荐设置** — 平衡相关性与跨域发现，推荐结果兼顾领域相近与领域差异"
   - β = 0.30："鼓励跨域探索，推荐结果中跨领域书籍占比增加"
   - β = 0.35："积极跨域发现，推荐结果更侧重不同领域的书籍"
   - β = 0.40："强调领域差异，推荐结果以完全不同领域的书籍为主"
   - β ≥ 0.45："大胆跨界探索，推荐结果几乎全部来自完全不同的领域"
4. **说明文本样式**：使用较小字号（12px）、浅灰色文字、行距适中，不干扰滑块操作区域
5. **推荐值标记**：在滑块轨道上以小圆点或竖线标记β=0.25的推荐位置（视觉提示，非文字）

### 2.2 加权效用函数增强

**现有公式**（原"综合排序"算法）：

```
FinalScore = CombinedSimilarity × OverlapCoefficient
```

**增强后的加权效用函数**（新"综合排序"算法）：

```
FinalScore = w_sim × CombinedSimilarity × OverlapCoefficient + w_rating × NormalizedRating + w_fresh × NormalizedFreshness
```

其中：

- `w_sim`：相似度权重（默认0.7）
- `w_rating`：评分权重（默认0.2）
- `NormalizedRating = rating / 10`（归一化到0-1）
- `w_fresh`：新鲜度权重（默认0.1）
- `NormalizedFreshness`：基于出版日期的归一化值（越新越高）

**排序模式调整**：

| 排序模式 | 排序依据 | 说明 |
|----------|----------|------|
| 综合排序 | 加权效用函数 FinalScore | **替换原算法**，综合考虑相似度×重叠系数 + 评分 + 新鲜度 |
| 相似度排序 | CombinedSimilarity × OverlapCoefficient | **新增**，使用原"综合排序"算法，仅按相似度与重叠系数排序 |
| 评分排序 | rating | 不变，按图书评分从高到低排序 |
| 最新排序 | publication_date | 不变，按出版日期从新到旧排序 |
