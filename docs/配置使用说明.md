# 数据库配置使用说明

## 概述

本项目现在使用配置文件管理数据库连接信息，不再硬编码在代码中。这样您和其他开发者可以轻松配置不同的数据库连接。

## 配置步骤

### 1. 创建配置文件

项目根目录下已经提供了 `config.example.json` 作为模板。请复制此文件并命名为 `config.json`：

```bash
# Windows
copy config.example.json config.json

# Linux/Mac
cp config.example.json config.json
```

### 2. 修改配置

打开 `config.json` 文件，根据您的实际数据库配置修改以下参数：

```json
{
  "database": {
    "host": "localhost",          // 数据库主机地址
    "port": 3306,                 // 数据库端口
    "user": "root",                // 数据库用户名
    "password": "your_password",  // 数据库密码
    "database": "test",            // 数据库名称
    "table": "books"               // 表名
  },
  "recommender": {
    "alpha": 0.4,
    "a": 0.6,
    "beta": 0.25
  }
}
```

### 3. 确保配置文件安全

- `config.json` 已经被添加到 `.gitignore` 中，不会被提交到版本控制系统
- 请妥善保管您的数据库密码
- 只分享 `config.example.json` 给其他开发者

## 配置说明

### 数据库配置参数

| 参数 | 说明 | 示例 |
|------|------|------|
| host | 数据库服务器地址 | localhost, 192.168.1.100 |
| port | 数据库端口 | 3306 (MySQL默认) |
| user | 数据库用户名 | root, admin |
| password | 数据库密码 | your_secure_password |
| database | 数据库名称 | test, book_recommend |
| table | 数据表名 | books |

### 推荐器配置参数

| 参数 | 说明 | 默认值 |
|------|------|--------|
| alpha | 关键词相似度加权系数 | 0.4 |
| a | 综合相似度加权系数 | 0.6 |
| beta | 跨域系数 | 0.25 |

## 远程数据库连接

如果要连接远程数据库，只需修改 `host` 为远程服务器地址：

```json
{
  "database": {
    "host": "your-remote-server.com",
    "port": 3306,
    ...
  }
}
```

**注意**：确保远程数据库允许您的IP地址访问，并正确配置了防火墙规则。

## 测试配置

运行以下命令测试配置是否正确：

```bash
python config.py
```

如果配置正确，您会看到类似以下的输出：

```
配置加载成功！

数据库配置:
  host: localhost
  port: 3306
  user: root
  password: ***
  database: test
  table: books

推荐器配置:
  alpha: 0.4
  a: 0.6
  beta: 0.25
```

## 常见问题

### Q: 找不到配置文件怎么办？
A: 确保您已经将 `config.example.json` 复制为 `config.json`，并且文件在项目根目录下。

### Q: 如何恢复默认配置？
A: 删除或重命名 `config.json`，然后重新从 `config.example.json` 复制一份。

### Q: 可以在代码中覆盖配置吗？
A: 可以！大部分类都支持通过参数覆盖配置文件中的设置。例如：

```python
recommender = CrossDomainRecommender(
    host='custom-host.com',
    user='custom-user'
)
```

### Q: 配置文件支持哪些格式？
A: 目前只支持 JSON 格式。
