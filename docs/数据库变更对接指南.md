# 数据库变更对接指南

## 一、新增 book\_also\_like 表

这是新增的关系表，每本推荐书名写一行记录。

**建表语句：**

```sql
CREATE TABLE IF NOT EXISTS book_also_like (
    relation_id      INT AUTO_INCREMENT PRIMARY KEY,
    source_book_id   INT NOT NULL,
    target_book_id   INT,
    target_book_name VARCHAR(255) NOT NULL,
    match_type       ENUM('exact','fuzzy','unmatched') NOT NULL DEFAULT 'unmatched',
    match_score      FLOAT DEFAULT 0.0,
    weight           FLOAT DEFAULT 1.0,
    created_at       TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    UNIQUE KEY uk_source_target (source_book_id, target_book_name),
    INDEX idx_source_book (source_book_id),
    INDEX idx_target_book (target_book_id),
    INDEX idx_match_type (match_type),
    CONSTRAINT fk_also_like_source FOREIGN KEY (source_book_id) REFERENCES books(book_id) ON DELETE CASCADE,
    CONSTRAINT fk_also_like_target FOREIGN KEY (target_book_id) REFERENCES books(book_id) ON DELETE SET NULL
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci;
```

**各字段填写说明：**

| 字段                 | 填什么              | 举例        |
| ------------------ | ---------------- | --------- |
| `source_book_id`   | 当前书的book\_id     | 5         |
| `target_book_id`   | **填NULL**        | NULL      |
| `target_book_name` | 豆瓣页面上的原始书名，原样保留  | 设计模式      |
| `match_type`       | **填'unmatched'** | unmatched |
| `match_score`      | **填0.0**         | 0.0       |
| `weight`           | **填1.0**         | 1.0       |

***

## 二、写入示例

假设《代码大全》book\_id=5，豆瓣页面"喜欢这本书的人也喜欢"列出了3本书：

**books表更新：**

```sql
UPDATE books SET also_like = '["设计模式", "代码整洁之道", "重构"]' WHERE book_id = 5;
```

**book\_also\_like表插入：**

```sql
INSERT INTO book_also_like (source_book_id, target_book_name, match_type, match_score, weight) VALUES
(5, '设计模式', 'unmatched', 0.0, 1.0),
(5, '代码整洁之道', 'unmatched', 0.0, 1.0),
(5, '重构', 'unmatched', 0.0, 1.0);
```

***

## 三、注意事项

1. **先插books再插book\_also\_like** — source\_book\_id有外键约束，books表中必须先有对应记录
2. **target\_book\_name保持原样** — 不要清洗、不要去掉书名号、不要改格式，豆瓣显示什么就存什么
3. **target\_book\_id留NULL** — 不需要你做书名匹配，后续我来处理
4. **同一本书同一推荐书名不会重复** — 唯一约束(source\_book\_id, target\_book\_name)会自动保证
